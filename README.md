# 📚 E-BOOK-SITE

A responsive and user-friendly e-book website built using **HTML** and **CSS**. The website provides an intuitive interface where users can browse books, register, log in, and explore different sections through a clean and modern design.

---

## 📌 Project Overview

The E-BOOK-SITE is a front-end web application designed to simulate an online book store or digital library. It includes multiple web pages for user authentication, product browsing, and informational content while maintaining a responsive and attractive layout.

---

## ✨ Features

- 📖 Home page showcasing books
- 👤 User Registration page
- 🔑 Login page
- 📚 Product/Books page
- ℹ️ About page
- 🎨 Responsive and modern UI
- 📱 Mobile-friendly design
- 🖥️ Easy navigation between pages

---
